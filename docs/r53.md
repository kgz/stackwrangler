# Route 53 hosted zones + records

`route53` is in LocalEmu `SERVICES` and profile `local` (same IAM endpoint as
other control-plane APIs, usually `:4566`).

| Kind | Create / records | Resolve |
|------|------------------|---------|
| **Public** zone | `create-hosted-zone` (no VPC) + `change-resource-record-sets` A / A-alias / CNAME | Emulator resolver answers on **loopback** (`dig @127.0.0.1` inside the LocalEmu container) and on every VPC DNS address |
| **Private** zone | Associate a VPC at create (or later); `HostedZoneConfig.Comment` is optional | Workloads with `--dns` pointing at that VPC's resolver address · [r53-private.md](r53-private.md) |

Public-zone resolution from the **host** network (published DNS port / host
`dig` without `docker exec`) and alias to API Gateway custom domains: [#300](https://github.com/kgz/awsl/issues/300).
Console: [#245](https://github.com/kgz/awsl/issues/245).

## Smoke

```bash
./smokes/networking/route53-smoke.sh
```

Uses compose project `awsl-wt-56-r53` and host port `24556` by default
(`AWSBOX_R53Z_HOST_PORT`, `AWSBOX_R53Z_*` for S3/ECR/SFTP/creds) so it does not
clash with a stack already on `:4566`. Tear-down is automatic unless
`AWSBOX_R53Z_KEEP=1`.

Checks:

- Public zone + UPSERT A, same-zone A-alias, CNAME
- `list-resource-record-sets` shows all three
- Resolver answers `dig @127.0.0.1` (UDP/53 on loopback inside LocalEmu)
- Private zone create still works
- Profile `local` can `list-hosted-zones` (with endpoint override to the smoke port)
- IAM deny of `route53:ListHostedZones`

Private VPC resolution / ELB alias connect: `./smokes/networking/r53-private-smoke.sh`.

Slice shape (domain-plugin zone + records):
`examples/serverless-v3-rest/slices/dns/`.
