Create data stream

Create a Kinesis data stream with provisioned shards or on-demand capacity. LocalEmu accepts both modes via CreateStream. Retention, encryption, and tags apply after the stream is ACTIVE.

Stream details

1–128 characters. Letters, numbers, underscores, hyphens, and periods.

Capacity mode

Required for provisioned mode. Each shard provides 1 MiB/s or 1000 records/s ingress.

Additional settings

LocalEmu default is 24 hours.
