# Security policy

## Supported versions

Report vulnerabilities against the default branch (`main`). There is no LTS train yet.

## Reporting a vulnerability

**Do not** open a public issue for security bugs.

Use GitHub’s private vulnerability reporting for this repository:

https://github.com/kgz/stackwrangler/security/advisories/new

Include enough detail to reproduce (affected component, version/commit, steps, impact). We will acknowledge the report and coordinate a fix and disclosure timeline.

If private reporting is unavailable, contact the repository owner [@kgz](https://github.com/kgz) directly and mark the message as a security report.
