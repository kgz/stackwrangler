# Security policy

## Supported versions

Report vulnerabilities against the default branch (`main`). There is no LTS train yet.

## Reporting a vulnerability

**Do not** open a public issue for security bugs.

Use GitHub’s private vulnerability reporting for this repository (Security → Advisories → Report a vulnerability):

https://github.com/kgz/stackwrangler/security/advisories/new

That form is enabled with the public visibility flip (`bin/make-public.sh --flip`). Include enough detail to reproduce (affected component, version/commit, steps, impact). We will acknowledge the report and coordinate a fix and disclosure timeline.

If private reporting is unavailable (for example while the repository is still private), contact the repository owner [@kgz](https://github.com/kgz) directly and mark the message as a security report.
